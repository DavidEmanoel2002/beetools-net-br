# Plano: Site de Vendas para Ferramentas Digitais

Criação de um site moderno e profissional para venda de produtos digitais, inspirado no pluffy.site, com foco em conversão e catálogo de produtos.

## Design e Experiência do Usuário
- Layout moderno e profissional com foco em confiança.
- Navegação intuitiva com Hero Section, Grade de Produtos e FAQ.
- Design responsivo e otimizado para SEO.

## Funcionalidades
- Catálogo de ferramentas digitais com categorias.
- Sistema de checkout simplificado (simulado inicialmente).
- Seção de depoimentos e benefícios para aumentar a conversão.

## Detalhes Técnicos
- **Frontend**: React 19 com TanStack Router.
- **Estilização**: Tailwind CSS v4 com componentes Shadcn UI.
- **Backend**: Lovable Cloud (Supabase) para gerenciamento de produtos e pedidos.
- **SEO**: Metadados dinâmicos e tags Open Graph para melhor visibilidade.

### Estrutura de Pastas e Componentes
- `src/components/layout`: Header, Footer.
- `src/components/products`: Card de Produto, Grade de Produtos.
- `src/components/home`: Hero, Features, Testimonials.
- `src/routes/index.tsx`: Página principal consolidada.
